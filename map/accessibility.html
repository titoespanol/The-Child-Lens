Accessibility

We want Mapping Children’s Health to be useful to people with different access needs. Accessibility work is ongoing. We have not completed a full accessibility audit or established conformance with an accessibility standard.

Ways to explore

The directory provides organisation information as text and links, alongside search and filters. You can use it without interacting with the map. Use the Map and Directory navigation links to switch views.

Keyboard and motion

Controls support keyboard navigation and show a focus indicator. Filter dialogs can be closed with Escape or Done. The site uses your device’s reduced-motion preference to reduce interface animation. Please tell us if a control is difficult to reach or use.

What still needs checking

We have made targeted checks of keyboard controls, phone layouts, text contrast and filter focus. These checks do not cover every page or combination of device and assistive technology. Full zoom, screen-reader and Safari/Firefox testing remain incomplete. The map is a complex interactive view; the directory is available as an alternative.

Report an access problem

Email map@thechildlens.com. Tell us which page or control caused difficulty and what you were trying to do. If useful, include your browser or assistive technology. Please avoid sending passwords, patient information or other sensitive details.
